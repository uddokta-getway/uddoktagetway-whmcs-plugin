# UddoktaPay Payment Gateway Plugin for WHMCS

An official/community WHMCS payment gateway module for **[Uddoktagetway.com](https://uddoktagetway.com)**, enabling automated online payments (MFS, cards, mobile banking, and internet banking) with instant settlement.

---

## 📂 File Structure

Make sure your files are placed in the correct directories inside your WHMCS installation:

```text
your-whmcs-root/
│
└── modules/
    ├── gateways/
    │   ├── uddoktagetway.php
    │   └── callback/
    │       └── uddoktagetway.php
